##  Concept Overview

### Introduction to Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming paradigm that organizes code into **objects**, allowing developers to model real-world entities efficiently.

### Four Pillars of OOP
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

### Benefits of OOP
- Code Reusability
- Better Security
- Easy Maintenance
- Modular Development
- Real-World Modeling

---

### Class and Object Creation

A **Class** is a blueprint that defines the properties (variables) and behaviors (methods) of an object.

An **Object** is an instance of a class that can access its variables and methods.

**Learned Concepts**
- Creating classes
- Creating multiple objects
- Accessing instance variables
- Calling methods using objects

---

###  Constructors

A **Constructor** is a special method that is automatically executed when an object is created.

#### Default Constructor
- Provided automatically by Java when no constructor is defined.

#### No-Argument Constructor
- A constructor written by the programmer without parameters.

#### Parameterized Constructor
- Initializes object values during object creation.

#### Constructor Overloading
- Multiple constructors with different parameter lists within the same class.

---

###  Display Method

A display method is a user-defined method used to print object information.

**Practiced**
- Displaying object details
- Calling display methods using objects

---

###  Method Overloading

Method Overloading allows multiple methods with the same name but different parameter lists.

It is an example of **Compile-Time Polymorphism**.

**Learned**
- Overloading methods using:
  - Different number of parameters
  - Different parameter types

---

###  `this` Keyword

The `this` keyword refers to the **current object**.

**Uses of `this`**
- Access current object's variables
- Differentiate local and instance variables
- Invoke another constructor using `this()`
- Refer to the current object
