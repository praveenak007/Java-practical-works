#  Java Learning Journey – Inheritance & Encapsulation

##  Topics Covered

Today, I learned two fundamental concepts of **Object-Oriented Programming (OOP)**: **Inheritance** and **Encapsulation**. These concepts help in building reusable, secure, and maintainable Java applications.

---

#  Introduction to Inheritance

**Inheritance** is the process by which one class acquires the properties and methods of another class. It enables code reusability and establishes an **"is-a"** relationship between classes.

### Key Concepts
- Parent Class (Superclass/Base Class)
- Child Class (Subclass/Derived Class)
- `extends` Keyword
- Code Reusability
- Parent-Child Relationship

---

##  Advantages of Inheritance

- Code Reusability
- Reduces Code Duplication
- Easy Maintenance
- Improves Readability
- Supports Method Overriding
- Represents Real-World Relationships

---

##  Types of Inheritance in Java

- Single Inheritance
-  Multilevel Inheritance
-  Hierarchical Inheritance
-  Multiple Inheritance (Not supported using classes)
-  Multiple Inheritance through Interfaces

---

##  super Keyword

The **`super`** keyword refers to the immediate parent class.

### Uses of `super`
- Access Parent Class Variables
- Access Parent Class Methods
- Invoke Parent Class Constructor

---

##  Method Overriding

Method Overriding allows a child class to provide its own implementation of a method already defined in the parent class.

### Key Points
- Runtime Polymorphism
- Same Method Name
- Same Parameters
- Different Implementation

---

# Introduction to Encapsulation

**Encapsulation** is the process of wrapping data (variables) and methods into a single unit (class) while restricting direct access to data.

### Key Concepts
- Data Hiding
- Private Variables
- Public Methods
- Controlled Access
- Security

---

##  Advantages of Encapsulation

- Data Security
- Data Hiding
- Better Control Over Data
- Easy Maintenance
- Increased Flexibility
- Improved Code Organization

---

##  Access Modifiers

- `private`
- `default`
- `protected`
- `public`
